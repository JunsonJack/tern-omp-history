# OMP History for Tern

![OMP History 截图](public/screenshot.png)

在 Tern 左侧浏览当前 OMP 数据目录下所有项目的会话，按最近修改时间排列；点击会话在当前标签右侧分屏恢复。可按标题、目录或会话 ID 搜索；列表超长时截断显示前 150 条并提示剩余数量，底部显示结果总数。

无搜索词时会话按工作目录分组：组头显示项目名、会话数和折叠箭头，组间按组内最新会话时间排列（空目录的会话沉底）。点击组头折叠/展开该组，折叠状态持久化，跨插件重载保留。搜索时退回平铺列表。

会话可归档：主列表卡片上有归档按钮，归档后从主列表移入归档视图（工具栏"归档"按钮进入，卡片带项目名徽标，可一键恢复）；归档状态持久化，跨插件重载保留。搜索仅在当前视图内过滤。

会话可彻底删除：卡片上有删除按钮，点击后弹出确认框（显示会话标题，可选"彻底删除"或取消），确认后才删除会话目录；归档记录随之清除。删除经 Tern 的文件 API 执行，仅删除 OMP 会话数据，不涉及其他文件。若会话目录里除会话 jsonl 外还有其他文件（多个会话共享同一目录），则退回只删除该会话的 jsonl 文件。

会话卡片的时间显示为“今天”“昨天”或完整日期时间，后面以 ` · ` 分隔工作目录名。归档视图的卡片会额外显示项目名。

## 安装

需要 Tern、OMP 和 Python。插件首选 `python` 运行索引脚本，找不到时自动回退 `python3`，无需手动改代码。在本目录执行：

```sh
tern plugin link .
```

侧边栏默认隐藏。点击窗口右上角的历史图标，或使用命令面板中的 `OMP History: toggle sidebar`、`⌘⌥⇧H` 显示或隐藏；关闭侧边栏面板也会隐藏其他标签页的历史侧边栏。插件会记住切换状态。侧边栏内可搜索和刷新，索引每 30 秒自动刷新。

历史图标使用 Tern 小组件实现，安装后会加入现有小组件设置，并在需要时显示小组件栏。点击图标时 Tern 会打开小组件详情，可按 `Esc` 关闭；隐藏小组件栏时，可使用命令面板或快捷键切换。图标位置依赖 Tern 当前的窗口样式，Tern 更新后可能需要调整。

Tern 的 `tiles` 布局在一个标签已有多个面板时可能将新侧栏放到窗口外。若看不到侧栏，请将窗口布局切换为 `rail`；插件不会修改全局布局设置。

也可使用命令面板中的 `OMP History: search and resume` 搜索并恢复会话，不受侧边栏布局影响。

会话来自 `$PI_CODING_AGENT_DIR/sessions`；未设置时使用 `~/.omp/agent/sessions`。Tern 启动环境决定该变量的值。插件读取会话头部和文件修改时间，不读取或上传聊天正文。恢复会话时使用原始工作目录；若目录不存在，OMP 会报告启动错误。

开发时修改插件文件后 Tern 会自动重新加载。`tern plugin unlink omp-history` 可卸载链接。

运行侧边栏关闭回归测试（会打开使用独立配置的 Tern 窗口）：

```sh
OMP_HISTORY_UI_TEST=1 python -m unittest -v test_sidebar   # Windows 用 python；macOS/Linux 可用 python3
```
